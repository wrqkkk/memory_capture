# Memory Capture

Memory Capture 是一个低摩擦的本地个人记忆捕捉工具。它用于记录人物观察、事件复盘、关系网络更新和自由想法，帮助把原本分散在日常互动中的感觉、判断和经验保存为可回看的 Markdown 文档。

这个工具不是日记软件，也不是任务管理器。它更像一个本地认知脚手架：当你对某个人、某件事、某段关系产生模糊感觉时，可以快速呼出窗口，把当时的观察、理解、感受和行动线索先保存下来，之后再慢慢提炼。

## Core Features

Memory Capture 支持四类记录。

**人｜观察** 用来记录某个人本身的特点，包括你观察到的信息、你的暂时理解、信息来源和后续行动指南。

**事｜复盘** 用来记录具体事件，包括事件简述、你的感知、你的行动、结果，以及下一次行动指南。

**关系｜网络更新** 用来记录你和某个人之间关系状态的变化，包括基本信息、关系定位、最近交互、认识是否更新和行动指南。

**自由｜随手记录** 用来保存临时想法，包括主题、原始想法、可能的重要性和之后可以如何使用。

对于“人｜观察”和“关系｜网络更新”，同一个对象会持续写入同一个 Markdown 文件。每次保存都会生成一个 Entry ID，用于把同一次记录中分散在不同字段下的内容绑定起来。

## File Structure

程序运行后会在 `BASE_DIR` 指定的位置自动生成以下结构：

```text
BASE_DIR
├── 00_raw_archive
├── 01_people
├── 02_events
├── 03_relationships
├── 04_free_notes
├── index.md
├── daily_updates.md
└── error_log.txt
