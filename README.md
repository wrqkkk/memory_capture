# Memory Capture

**Memory Capture** 是一个本地运行的个人记忆捕捉工具，用来低摩擦地记录人物观察、事件复盘、关系网络更新和自由想法。它的目标不是替代你的思考，而是把那些原本靠感觉维持的判断、经验、互动线索保存成可以回看、比较和继续提炼的 Markdown 文档。

这个工具默认以 `.pyw` 文件运行，适合在 Windows 上双击启动。启动后不会弹出命令行窗口，可以通过快捷键呼出记录窗口。

## 核心功能

Memory Capture 当前包含四类记录。

**人｜观察** 用来记录你对某个人本身的观察。它会把同一个对象持续更新到同一个 Markdown 文件中，适合长期积累“我观察到的信息”“我的理解”“信息来源”和“行动指南”。

**事｜复盘** 用来记录具体事件。它适合保存某件事的时间、地点、人物、起因经过结果，以及你当时的感知、行动、结果和下一次行动指南。

**关系｜网络更新** 用来记录你和某个人之间关系状态的变化。它和“人｜观察”分开，因为一个人本身的特点和你与这个人的关系状态并不是同一件事。

**自由｜随手记录** 用来保存暂时还没有归类的原始想法。它适合记录灵感、片段、问题、之后可能会用到的材料。

## 文件结构

程序会在 `BASE_DIR` 指定的目录下自动生成以下结构：

```text
BASE_DIR
├── 00_raw_archive
├── 01_people
├── 02_events
├── 03_relationships
├── 04_free_notes
├── index.md
├── daily_updates.md
└── error_log.txt
```

`00_raw_archive` 保存每一次记录的完整原始快照。即使某些内容被拆分写入不同栏目，也可以通过这里找到当时那次完整输入。

`01_people` 保存“人｜观察”记录。同一个人的更新会持续追加到同一个文件中。

`02_events` 保存“事｜复盘”记录。每一次事件复盘都会生成一个独立文件。

`03_relationships` 保存“关系｜网络更新”记录。同一个对象的关系更新会持续追加到同一个文件中。

`04_free_notes` 保存“自由｜随手记录”。每一次自由记录都会生成一个独立文件。

`index.md` 是机器索引，一行对应一次保存。它用于追踪 Raw Snapshot、生成热力图和重建每日目录。

`daily_updates.md` 是人类可读的每日更新目录。它按年、月、日整理每天更新了什么，没有记录的日期不会显示。

`error_log.txt` 保存程序运行中的错误信息，便于排查问题。


## 安装依赖

这个项目需要 Python 3，并依赖两个包：

```text
customtkinter
keyboard
```

运行：

```powershell
pip install -r requirements.txt
```

也可以直接安装：

```powershell
pip install customtkinter keyboard
```

如果 `keyboard` 在 Windows 上无法监听全局快捷键，可能需要以管理员权限运行程序。

## 配置

打开 `personal_memory_capture.pyw`，在顶部修改保存路径：

```python
BASE_DIR = Path(r"D:\26SPRING\Project3-个人记忆系统")
```

默认快捷键是：

```text
Ctrl + Alt + M
```

用于呼出记录窗口。

```text
Ctrl + Alt + Shift + Q
```

用于退出后台监听程序。

## 使用方式

双击运行：

```text
personal_memory_capture.pyw
```

程序启动后会在后台运行。需要记录时，按：

```text
Ctrl + Alt + M
```

窗口顶部需要填写标题或对象名。不同分类下含义不同：

```text
人｜观察：姓名 / 对象
关系｜网络更新：姓名 / 对象
事｜复盘：事件标题
自由｜随手记录：主题
```

内容字段不需要全部填写。空白字段不会写入长期文档。

保存后，程序会自动完成以下动作：

```text
写入正式记录文件
写入 00_raw_archive 中的完整快照
更新 index.md
重建 daily_updates.md
更新热力图统计数据来源
```

## Entry ID 是什么

每一次保存都会生成一个 Entry ID，例如：

```text
20260425_210815
```

它是系统内部的追踪编号。

在“人｜观察”和“关系｜网络更新”中，同一次保存的内容可能会分散写入不同栏目。Entry ID 可以把这些分散内容重新绑定起来。例如：

```markdown
## 我观察到的信息
- [20260425_210815｜2026-04-25 21:08:15] 她今天在别人说不下去的时候补了一句很关键的话。

## 我的理解
- [20260425_210815｜2026-04-25 21:08:15] 她可能不是外放型表达，但会观察整体气氛。

## 信息来源
- [20260425_210815｜2026-04-25 21:08:15] 今天三个人一起聊天时。
```

如果以后想找到当时完整输入，也可以用 Entry ID 去 `00_raw_archive` 中检索对应快照。

## 每日目录

程序会自动生成 `daily_updates.md`。它按年、月、日整理每天更新了哪些记录。

示例：

```markdown
# 每日更新目录

## 2026

### 2026-04

#### 2026-04-25

**今日更新：2 条**

- [21:50] **人｜观察**｜[Tom](01_people/Tom.md)
- [22:01] **人｜观察**｜[Any](01_people/Any.md)
```

这个文件适合每天或每周回看：“我最近到底更新了什么？”

## 热力图

主窗口底部有“查看记录热力图”按钮。热力图从 `index.md` 读取记录数量。

每个小方块代表一天，颜色越深表示当天记录越多。点击某一天可以查看当天记录条目。鼠标悬停在方块上会显示日期和记录数量。
